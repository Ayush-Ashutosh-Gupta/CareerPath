\# CareerPath



CareerPath is a student guidance tool designed to help users explore career options, exam routes, and planning decisions in a structured way.



\## Features



\- Career and exam exploration

\- Comparison-oriented layout

\- Student-focused planning utilities



\## Purpose



A practical helper for students making academic and career decisions.
